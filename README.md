# TopDeckSearch

Неофициальное приложение для просмотра MTG-аукционов, синглов и завершённых лотов [TopDeck.ru](https://topdeck.ru): вишлист, фильтры, история цен и уведомления о новых аукционах. Ставки делаются на сайте по ссылке.

Вишлист и настройки хранятся на устройстве. Данные загружаются напрямую с TopDeck, названия карт при добавлении в вишлист распознаются через Scryfall. Приложение не связано с администрацией TopDeck.

Нужен **Android 8.0 или новее**.

## Установка и обновление

1. Скачайте APK из раздела [Releases](https://github.com/IqIsDeleted/TopDeckSearchPublic/releases).
2. Откройте файл на телефоне и разрешите установку из выбранного источника, если Android попросит.
3. Для обновления установите новый APK поверх приложения — вишлист и настройки сохранятся при прежней подписи.

Не удаляйте приложение перед обновлением: удаление стирает локальные данные.
